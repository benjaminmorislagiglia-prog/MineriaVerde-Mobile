# Mineria Verde

Proyecto organizado para mantener separados los modulos web, movil, backend y base de datos.

```txt
MineriaVerde/
├── API_GESTIONWEB/          # Frontend web en React
├── mobile-app/              # App movil React Native + Expo
├── API_GESTIONSTOCKMDR/     # Backend ASP.NET Web API
├── database/                # Scripts SQL, si se decide moverlos luego
└── README.md
```

Por ahora se conservan los nombres existentes de las carpetas web y backend para no romper configuraciones ya funcionales.
